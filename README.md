# DevSecOps

Практические и контрольные работы по дисциплине DevSecOps.

## Структура проекта

| Работа | Описание |
|---|---|
| [КТ-1 Ansible](KT1_Ansible/README.md) | Автоматизация настройки Linux-серверов с помощью Ansible |
| КТ-2 Docker | Контейнеризация и управление контейнерами |
| КТ-3 Monitoring | Мониторинг и сбор метрик |
| КТ-4 Kubernetes | Оркестрация контейнеров |

## Используемые технологии

- Linux
- Ansible
- Docker
- Prometheus
- Kubernetes

## Автор

Практические работы выполнены в рамках изучения DevSecOps.
