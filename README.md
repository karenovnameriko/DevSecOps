# DevSecOps

Практические и контрольные работы по дисциплине DevSecOps.

## Структура проекта

| Работа | Описание |
|---|---|
| [КТ-1 Ansible](KT1_Ansible/README.md) | Автоматизация настройки Linux-серверов с помощью Ansible |
| [КТ-2 Docker](KT2_Docker/README.md) | Контейнеризация и управление контейнерами |
| [КТ-3 Monitoring](KT3_Monitoring/README.md) | Мониторинг и сбор метрик |
| [КТ-4 Kubernetes](KT4_Kubernetes/README.md) | Оркестрация контейнеров |

## Используемые технологии

- Linux
- Ansible
- Docker
- Prometheus
- Kubernetes

Практические работы выполнены в рамках изучения DevSecOps.
